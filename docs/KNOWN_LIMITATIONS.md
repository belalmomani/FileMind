# القيود المعروفة (حالة صادقة)
- **لم يُتحقق من البناء الكامل بعد**: راجع نتيجة GitHub Actions قبل أي اعتماد.
- Android 13+: MediaStore يعرض الوسائط فقط؛ PDF/ZIP/APK والمجلدات الأخرى تُضاف عبر «إضافة مجلد» (SAF). `Android/data` و`Android/obb` غير متاحة.
- النقل/الاستبدال عبر SAF **ليس ذرّياً**؛ يُكتب ملف مؤقت ويُتحقق منه قبل حذف القديم.
- العمليات تعمل داخل التطبيق ولا تُستكمل تلقائياً بعد إغلاقه (لا WorkManager بعد).
- التراجع متاح لإعادة التسمية فقط، وليس للنقل أو الحذف.
- إعادة التسمية تعمل لملفات المجلدات المضافة فقط (ليس عناصر MediaStore).
- الأرشيفات: ZIP فقط. RAR/7Z معلومات فقط. لا إنشاء أرشيفات. كشف التشفير يتم عند الاستخراج.
- المكررات: تطابق دقيق (SHA-256) فقط؛ لا تشابه بصري (perceptual hash) بعد.
- خريطة التخزين: شريط تناسبي حسب النوع، وليست treemap متداخلة بعد.
- فترة «تحتاج مراجعة» ثابتة على 6 أشهر في التصنيف (غير قابلة للتعديل بعد، لكن فلتر «قبل 6 أشهر» متاح).
- Start.io: نقطة الدمج جاهزة (`AdsManager`) لكن مكتبة SDK لم تُضف؛ تحتاج معرّف تطبيقك ومراجعة وثائقهم.
- لا مقارنة أرشيفات/مجلدات ولا «كشف الملفات المفقودة من مجموعة مرجعية» بعد.
- لا تخزين سحابي بعد.
