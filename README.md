# FileMind
مدير ملفات ذكي لأندرويد (Kotlin + Compose). **الحالة: أساس المشروع — لم يكتمل بعد.**

## ما هو منفذ
- محرك نقل/نسخ آمن مع كشف التعارض ومقارنة المحتوى (SHA-256) واستبدال عبر ملف مؤقت: `core/FileTransfer.kt`
- إعادة تسمية جماعية مع معاينة وكشف تعارض: `core/BulkRenamer.kt`
- مخطط التنظيم (اسم/سنة/شهر/امتداد/نوع، تاريخ مجهول): `core/Organizer.kt`
- كشف المكررات المتطابقة (للقراءة فقط): `core/DuplicateFinder.kt`
- محلل أوامر عربية محلي: `core/ArabicQueryParser.kt`
- ألوان الأنواع موحدة، ثيم فاتح/داكن/تلقائي، إعدادات DataStore، نقطة دمج إعلانات Start.io
- اختبارات وحدات في `app/src/test`

## المرحلة 2 (نحو 50%) — مكتوبة وغير مبنية بعد
- فحص حقيقي: MediaStore (الوسائط) + SAF لأي مجلد/بطاقة SD يمنحه المستخدم، مع الإبلاغ عن المجلدات التي تعذر فحصها
- التصنيفات (14 تصنيفاً) كعروض افتراضية، شريط فلترة (AND/OR، حجم، قدم، مخفية، فرز) يُحفظ لكل قسم في Room
- نقل/نسخ عبر SAF مع نافذة تعارض (حجم/تاريخ/موقع/تطابق SHA-256/تطبيق على الكل) واستبدال بملف مؤقت وتحقق
- حذف (SAF مباشر، MediaStore عبر طلب النظام)، فتح، مشاركة، تحديد جماعي
- سجل عمليات Room مع بحث، شاشة مجلدات بأيقونة متعددة الألوان من المحتوى الفعلي، «اسأل ملفاتك» عبر المحلل المحلي
- إعدادات: ثيم، مجلدات مضافة، حالة Start.io

## البناء
1. انسخ `local.properties.example` إلى `local.properties` واضبط `sdk.dir` و`startio.appId`.
2. للإصدار الموقّع: انسخ `keystore.properties.example` إلى `keystore.properties`.
3. `./gradlew test` ثم `./gradlew assembleRelease` (يلزم إضافة Gradle wrapper: `gradle wrapper`).

**لم يُبنَ المشروع ولم تُشغَّل الاختبارات** في بيئة الإنشاء (لا Gradle ولا Android SDK ولا شبكة). إصدارات التبعيات لم تُتحقق.
