# FileMind

مدير ملفات أندرويد ذكي (Kotlin + Jetpack Compose + Material 3 + Room + DataStore + WorkManager). واجهة عربية. **المبدأ: لا يُحذف أو يُستبدل شيء دون تأكيدك، ولا تُخترع بيانات غير معروفة.**

الحزمة: `com.filemind.smartmanager` · minSdk 26 · compileSdk/targetSdk 35

## الميزات
- **الاستعراض والإدارة:** متصفح هرمي كامل (قائمة/شبكة/تفاصيل، مفضلة، مجلد جديد، إعادة تسمية، حذف، معلومات، نسخ/نقل ملفات ومجلدات مع حماية من النقل داخل النفس).
- **المسح والتصنيف:** MediaStore + مجلدات SAF، 14 تصنيفاً، فهرس محلي سريع، فلاتر محفوظة بالاسم (AND/OR، تاريخ EXIF أو التعديل).
- **النقل الآمن:** نسخ مؤقت + تحقق بالبصمة، حوار تعارض (متطابق/مختلف/غير مقروء)، نسخة احتياطية قبل الاستبدال (اختيارية)، عمليات مجدولة قابلة للاستكمال والإيقاف، واستكمال **في الخلفية** بإشعار.
- **التنظيم:** تسمية جماعية بمعاينة وتراجع، منظّم ذكي بمعاينة ومهام محفوظة.
- **التحليل:** مكررات (SHA-256)، صور متشابهة (dHash)، تحليل مساحة بخريطة شجرية، خط زمني (أشهر حقيقية فقط).
- **المقارنة:** مجلد/ZIP/مرجع محفوظ، كشف المفقود، و**نسخ المفقود** بين مجلدين (بلا استبدال ولا حذف).
- **الأرشيفات:** ZIP كامل (عرض/استخراج آمن/إنشاء من المتصفح مع تحقق)، و7Z وRAR **عرض فقط**.
- **البحث:** نص وصوت عربي محلي يرفض الغموض.
- **الوحدات الخارجية:** اكتشاف USB/بطاقة SD مع منح وصول يدوي.
- **الإعدادات:** السمة، الجذور، فترة المراجعة، مدة السجل، النسخ الاحتياطي، تأكيد الحذف، حجم الأيقونات والأعمدة، تقارير الأعطال (معطّلة افتراضياً).
- **الإعلانات:** بانر Start.io صغير أسفل كل الشاشات، يختفي أثناء عمليات الملفات.

## الحدود الصريحة
القائمة الكاملة والمحدّثة في `docs/KNOWN_LIMITATIONS.md` (مثل: لا استخراج RAR/7Z، لا تخزين سحابي، SAF ليس ذرياً، أندرويد 13+ يعرض الوسائط فقط عبر MediaStore). **لم يُختبر التطبيق على أجهزة حقيقية بشكل منهجي بعد.**

## البناء (لا يحتاج حاسوباً)
- **GitHub Actions:** `build.yml` يشغّل الاختبارات ويبني APK debug عند كل رفع، ويفحص اكتمال الملفات مقابل `docs/FILES.txt`.
- **نسخ debug** تُوقَّع بمفتاح ثابت مشترك (`app/filemind-debug.keystore`، عام عمداً) لتتحدث فوق بعضها.
- **نسخة Play:** `release.yml` (يدوي) يبني AAB موقّعاً من أسرار GitHub. الخطوات في `docs/RELEASE.md`.
- محلياً: انسخ `local.properties.example` إلى `local.properties`، ثم `gradle test assembleDebug`.
